Le second processus a crashé deux fois en code natif : EXCEPTION_ACCESS_VIOLATION, `glfw.dll+0x101ab`, rapports `run-client-two/hs_err_pid14204.log` et `hs_err_pid21864.log`. Le second essai utilisait rendu 4 chunks / 30 FPS. Ce n'est pas une preuve que le gameplay à deux clients est validé. Ne pas répéter ces essais sans nouvelle hypothèse ; isoler l'interaction GLFW/fenêtres multiples/capture, ou vérifier sur une seconde machine.
