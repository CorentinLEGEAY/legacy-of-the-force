# Provenance des ressources

- `transaction_anchor.png` : texture originale 16×16 du projet, fond bleu sombre, bordure et diagonales cyan, générée par dessin de pixels. Modèle et blockstate JSON originaux.
- Les projections de blocs affichent les modèles déjà fournis par Minecraft pour les blocs du monde ; aucun asset de film ou jeu tiers extrait.
- Wrapper Gradle issu du MDK NeoForge officiel ; références et versions dans `validation/SOURCES_P0.md`, en-têtes du wrapper conservés.
- Aucun son ou modèle officiel Star Wars ajouté. La direction artistique complète et les crédits de release restent à finaliser en P7.
- Atelier, pièces et poignées P2-01 : géométries cuboïdes JSON originales du projet. Les matériaux référencent les textures vanilla déjà présentes dans Minecraft (fer, cuivre, béton noir et bloc de redstone) ; aucune image de Minecraft n'est recopiée dans le JAR du mod. Les deux émetteurs disposent de géométries distinctes. Sons et habillage avancés restent à produire.
